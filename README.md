## About

I make games and the tools around them. Co-founder of **Odlar Games**, a small indie studio.
I like gameplay systems that can be tested: deterministic rules engines, bots that learn by self-play,
netcode, and pipelines that let one person ship screenshots, trailers and builds from code.

Most source code is private; the games below can be downloaded and played.

### Inksworn: Tactics of Five — turn-based card tactics · Godot 4

## Tools (private repositories)

- **Forge** — keeps an AI-assisted project's context in order: an MCP server with project tools
  (state, tasks, changelog, ADRs), hybrid FTS5 + vector search fused with RRF, context packed to a token budget,
  rules served by relevance. Python, no external dependencies for the MCP protocol.
- **LLM NPC** — a Godot 4 character who talks through a local LLM (llama.cpp, Qwen): long-term memory on disk,
  fact extraction with a JSON schema, a trust model and an "under the hood" panel with the full prompt and token budget.
- **Game capture pipeline** — bot-vs-bot matches recorded deterministically from the game, then cut into trailers
  and shorts with Remotion and ffmpeg.
